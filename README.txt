PREVIEW:
Open index.html in a browser. Keep all files in the same folder.

PUBLISH WITH GITHUB PAGES:
1. Create a new public repository on GitHub (for example: alex-birthday).
2. Upload all five files from this folder to the repository's main/root folder.
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the main branch and /(root), then Save.
6. Wait a minute or two. Your site link will appear in the Pages section.

To change the birthday message, edit the text in index.html.
